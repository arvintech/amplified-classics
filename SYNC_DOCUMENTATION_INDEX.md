## ⚡ Quick Command Reference

### Most Common Commands (Bookmark These)

```bash
# Start work
git pull origin main
npm run dev

# Check status
git status

# Save work
git add [files]
git commit -m "Description"
git push origin main
```

```bash
# Start session
~/sync-amplified.sh start

# End session
~/sync-amplified.sh end
```
